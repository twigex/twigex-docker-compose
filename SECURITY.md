# Security Policy

## Supported configuration

Only the current `main` branch of this repo, run as documented in
[`README.md`](README.md), is supported. Single-node Docker
Compose only.

## Reporting a vulnerability

**Do not open a public issue for security problems.** Report privately:

1. **Preferred:** GitHub private security reporting for this repository
   (Security tab → "Report a vulnerability"). This creates a private
   thread with the maintainers only.
2. **Email:** [support@twigex.com](mailto:support@twigex.com) — put
   "SECURITY" in the subject line so it's triaged promptly.

Include: affected file/service, branch/commit, reproduction steps, and
impact. You'll get an acknowledgment within a few days; fixes land on
`main` and are noted in commit history.

## Secret inventory and rotation

All values live in the git-ignored `.env` (created by
`generate-secrets.sh` from `.env.example`). Keep `.env` out of
world-readable backups and never commit it.

Each cross-service secret is a **single `.env` variable consumed by both
of its services** — the pair cannot drift. The mapping to each service's
own variable name is in the contract map at the top of `.env.example`
and in `docker-compose.yml` comments.

| Secret | Service pair | Default | Rotation notes |
|---|---|---|---|
| `TWIGEX_ADMIN_PASSWORD` | twigex (first-boot admin) | `change-me` | Change on first login; app-level |
| `TWIGEX_DB_PASSWORD` | twigex ↔ mariadb | `change-me` | **One-time-set** — baked into DB on first init. Rotating later requires an `ALTER USER` inside the DB (see README → "Manual rotation"). |
| `MARIADB_ROOT_PASSWORD` | mariadb | `change-me` | **One-time-set** on first volume init — rotating needs an `ALTER USER` too (the backup command and the `ALTER USER` one-liner authenticate as root with this value) |
| `TWIGEX_REDIS_PASSWORD` | twigex + redis | `change-me` | Edit one line, `docker compose up -d` |
| `TWIGEX_OFFICE_SECRET` | twigex + eurooffice | `change-me` | Edit one line, `docker compose up -d` |
| `TWIGEX_CHANNEL_SECRET` (+ `TWIGEX_CHANNEL_KEY`) | twigex + livekit | `change-me` / `key` | **This is the real LiveKit auth boundary** — anyone with this string can mint valid tokens on port 7880 |
| `TWIGEX_SERVER_ENCRYPT_KEY` | twigex | (generated by script) | Exactly 32 hex chars. Encrypts stored secrets — **losing it loses access to stored credentials**. Back it up; rotate only with a migration plan |
| `TWIGEX_COLLIMATO_CUBE_API_SECRET` / `_CALLBACK_SECRET` | twigex + cube-api | `change-me` | Edit one line each, `docker compose up -d` |
| `TWIGEX_STORAGE_ACCESS_KEY` / `_SECRET_KEY` | twigex | `change-me` (script blanks them) | Only used when `TWIGEX_STORAGE_TYPE=s3` — provider keys, rotate at the provider |
| `TWIGEX_SMTP_PASSWORD` | twigex | empty | Only used with the other `TWIGEX_SMTP_*` vars; empty = SMTP configured in the GUI |
| `TWIGEX_LDAP_BIND_PASSWORD` | twigex | empty | Only used with the other `TWIGEX_LDAP_*` vars; empty = LDAP configured in the GUI |
| `TWIGEX_CHANNEL_GIF_API_KEY` | twigex | empty | GIF provider key (optional chat feature) |
| `TWIGEX_LICENSE` | twigex | empty | Empty = Community Edition; setting it locks the license in the GUI |

The one-shot generator is `generate-secrets.sh` (repo root).

## Known exposure caveats

- **Defaults are insecure on purpose** (`change-me`). The stack must not
  be exposed to anything beyond localhost until every `change-me` is
  replaced: `grep -v '^[[:space:]]*#' .env | grep -c change-me`
  must report 0.
- **Port 3000 is plain HTTP.** Terminate TLS with a reverse proxy before
  any exposure beyond the host. Same for 9980 (editor) and 7880 (chat;
  ICE needs TCP 7881 + UDP 7882, TURN uses UDP 50000–50100).
- **LiveKit ships with the literal key `key` / secret `change-me`.**
  Until rotated, treat port 7880 as open to any peer that has seen
  `.env.example`.
- **The generated `TWIGEX_SERVER_ENCRYPT_KEY` is the only copy of
  itself.** Back it up; there is no recovery path.
- **No HA / no external secret management.** Everything is `.env` on one
  host; protect its permissions (`chmod 600`, enforced by the script).
